从 JSON 预览到 SQLite 保存，再由 Worker 同步到 Notion

使用顺序

确认 FastAPI 与 Worker 都在运行，然后依次执行下方三步。预览只检查数据；点击“提交并同步”才会保存到 SQLite，Worker 随后向 Notion 写入页面。

此页面不需要输入 Notion Token。若尚未准备好自己的内容，可先载入示例，修改任务名称后试用。需要接口说明可打开 API 文档。

1粘贴任务 JSON

2检查预览结果

预览后会显示任务状态和知识路径。
提交会写入真实数据。新任务会保存在本地 SQLite，并由正在运行的 Worker 同步到你的 Notion。重复任务不会创建第二组页面。

3查看同步状态

提交后每 5 秒自动刷新；也可以输入已有的 Import ID 查询。
